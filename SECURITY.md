# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting for this repository and include the affected version, reproduction, impact, and any suggested mitigation.

Maintainers will acknowledge a report within seven days, keep the reporter informed while validating it, and coordinate disclosure after a fix is available. Please avoid accessing data that is not yours or disrupting services while testing.

Only the latest minor release receives security fixes during the 0.x series.
