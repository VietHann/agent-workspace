# Support

## Usage questions and ideas

Use [GitHub Discussions](https://github.com/VietHann/agent-workspace/discussions) for setup questions, workflow ideas, design feedback, and showing how your team customized a workspace. Search existing discussions before opening a new one.

## Bugs

Use the [bug report form](https://github.com/VietHann/agent-workspace/issues/new?template=bug.yml) for reproducible incorrect behavior. Include the `agent-workspace` version, Node.js version, operating system, exact command, repository signals, observed output, and expected output. Remove secrets and proprietary source.

## Extension proposals

Use the [extension proposal form](https://github.com/VietHann/agent-workspace/issues/new?template=extension.yml) for new skills, agents, detectors, adapters, packs, or rules. Explain the reproducible capability and how success can be validated.

## Security vulnerabilities

Do not report vulnerabilities in public issues or discussions. Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.

## Scope

Community support is best-effort. This project organizes existing coding agents; support for model behavior, vendor outages, IDE accounts, and proprietary integrations belongs with the relevant vendor.
